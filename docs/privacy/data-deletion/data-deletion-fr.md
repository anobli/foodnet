# Suppression des Données - FoodNet

**Dernière mise à jour : 25 mars 2026**

## Présentation

FoodNet respecte votre droit de supprimer vos données à tout moment. Cette page explique comment supprimer vos données de l'application FoodNet.

## Types de Données

FoodNet stocke deux types de données :

### 1. Données Locales
Données stockées sur votre smartphone, incluant :
- Produits alimentaires et dates de péremption
- Catégories et préférences
- Paramètres de l'application

### 2. Données Cloud (si vous êtes connecté)
Données synchronisées avec notre base de données Firestore, incluant :
- Votre adresse e-mail
- Données d'inventaire alimentaire
- Adhésions aux groupes

## Comment Supprimer Vos Données

### Suppression des Données Cloud (Méthode Recommandée)

Si vous utilisez la fonctionnalité de synchronisation cloud, vous pouvez supprimer vos données cloud directement depuis l'application :

1. **Ouvrez l'application FoodNet**
2. **Accédez au menu** (généralement accessible via les trois points ou l'icône hamburger)
3. **Sélectionnez "Supprimer le compte"** ou **"Retirer le compte"**
4. **Confirmez votre choix**

Vos données seront définitivement supprimées de notre base de données Firestore. Cela inclut :
- Votre adresse e-mail
- Toutes les données d'inventaire alimentaire synchronisées
- Adhésions aux groupes et données partagées

**Important :** Cette action est irréversible. Une fois supprimées, vos données cloud ne peuvent pas être récupérées.

**Note :** Se déconnecter du service ne supprimera pas vos données de nos serveurs. Vous devez utiliser l'option "Supprimer le compte" ou "Retirer le compte" pour supprimer définitivement vos données.

### Suppression des Données Locales

Pour supprimer les données stockées localement sur votre smartphone :

**Option 1 : Effacer les données de l'application**
1. Accédez aux **Paramètres** de votre appareil
2. Sélectionnez **Applications**
3. Trouvez et sélectionnez **FoodNet**
4. Appuyez sur **Stockage**
5. Appuyez sur **Effacer les données** ou **Effacer le stockage**

**Option 2 : Désinstaller l'application**
1. Accédez aux **Paramètres** de votre appareil
2. Sélectionnez **Applications**
3. Trouvez et sélectionnez **FoodNet**
4. Appuyez sur **Désinstaller**

## Délai de Suppression des Données

- **Données cloud** : Supprimées immédiatement sur demande depuis l'application
- **Données locales** : Supprimées immédiatement lorsque vous effacez les données de l'application ou la désinstallez

## Copies de Sauvegarde

Veuillez noter :
- Nous ne conservons pas de copies de sauvegarde de vos données au-delà de ce qui est stocké dans Firestore
- Une fois vos données cloud supprimées, elles sont définitivement retirées de nos serveurs
- Nous n'avons pas la possibilité de récupérer les données supprimées

## Vérification

Après avoir supprimé vos données :
- Si vous essayez d'accéder à votre compte depuis un autre appareil, vous devrez vous reconnecter
- Vos données ne seront plus synchronisées entre les appareils
- Les autres membres du groupe ne verront plus vos données partagées

## Politique de Confidentialité

Pour plus d'informations sur la manière dont nous traitons vos données, veuillez consulter notre [Politique de Confidentialité](../privacy-policy-fr.html).

## Vos Droits

En vertu des réglementations sur la protection des données (y compris le RGPD le cas échéant), vous avez le droit de :
- Accéder à vos données personnelles
- Rectifier les données inexactes
- Supprimer vos données (droit à l'oubli)
- Vous opposer au traitement des données
- Portabilité des données

FoodNet s'engage à respecter ces droits et à rendre la suppression des données simple et accessible.
